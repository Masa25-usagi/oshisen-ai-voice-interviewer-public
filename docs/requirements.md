# 要件メモ v0.1

## 目的

利用者が政策テーマについて話し、理由や迷いを含めて自分の考えを整理できること。音声インタビューの段階では候補者・政党・候補者回答を扱わず、回答確認後に既存の一致度計算へ渡せるデータだけを作る。

## 対象フロー

1. 質問、背景、賛成側と慎重側の論点を読む。
2. マイクを許可して音声インタビューを開始する。接続できない場合はデモまたはテキスト入力を使う。
3. AIが利用者の発言から回答候補、確信度、根拠要約を提案する。
4. 利用者が候補を確認、変更、または「まだ判断できない」を選ぶ。
5. 確定した回答だけを最終確認し、既存の一致度計算の入力境界へ渡す。

## 受け入れ条件

- 初期表示から5問の進行状況と現在の質問が分かる。
- Source Pack は賛成側・慎重側を同じ画面で確認でき、公式資料へのリンクを持つ。
- AI候補は利用者の確認前に確定回答として扱われない。
- マイク拒否、APIキー未設定、接続失敗時も画面が壊れずデモへ移れる。
- 候補者データが Realtime セッションの指示文、ツール引数、音声会話へ入らない。
- 回答の手動変更と保留が可能で、最終確認画面で状態を確認できる。

## 非目標

- このMVPでの候補者・政党データの収集、ランキング、投票推奨。
- 音声や文字起こしの恒久保存。
- Source Pack の自動リサーチ基盤。
